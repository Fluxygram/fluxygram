# fluxygram

**Diagrams that explain themselves.** Describe anything in JSON; Fluxygram draws it and tells it step by step, with motion that helps people understand.

This package is the single-file build of the `<fluxy-gram>` component: no install, no bundler.

```html
<script type="module" src="https://cdn.jsdelivr.net/npm/fluxygram@0.1"></script>

<fluxy-gram src="checkout.flux.json"></fluxy-gram>
```

- Make diagrams visually in the editor: https://fluxygram.salamancacmcol.workers.dev/play
- Let your AI agent write them: [the Fluxygram skill](https://github.com/Fluxygram/fluxygram/tree/main/skills/fluxygram)
- With a bundler, prefer [`@fluxygram/element`](https://www.npmjs.com/package/@fluxygram/element)
