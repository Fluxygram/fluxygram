# Fluxygram for Obsidian

Write the diagram JSON in a ` ```fluxygram ` code block and it plays as an animated, step-by-step diagram in your notes. Follows Obsidian's light or dark theme.

Build: `pnpm --filter @fluxygram/obsidian build` → `dist/main.js` and `dist/manifest.json` (copy both to `<vault>/.obsidian/plugins/fluxygram/`).
