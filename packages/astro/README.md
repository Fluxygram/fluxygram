# @fluxygram/astro

[Fluxygram](https://fluxygram.app) for Astro and Starlight: ` ```fluxygram ` code blocks in `.md` and `.mdx` become animated, step-by-step diagrams.

```js
// astro.config.mjs
import fluxygram from '@fluxygram/astro';

export default defineConfig({ integrations: [fluxygram()] });
```

Docs: https://docs.fluxygram.app/guides/integrations/
