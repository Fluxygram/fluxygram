## What you can do

<CardGrid>
  <Card title="Write it or draw it" icon="pencil">
    Write a `.flux.json` by hand, ask an AI agent to write it, or build it visually in the [editor](https://fluxygram.app/play). The layout is automatic.
  </Card>
  <Card title="Seven diagram types" icon="seti:pipeline">
    Flows, architectures, timelines, trees, cycles, sequences and mind maps. Each one moves in the way that explains it best.
  </Card>
  <Card title="Tell a story" icon="list-format">
    Steps reveal the diagram one idea at a time: what appears, what travels, what succeeds and what fails.
  </Card>
  <Card title="Embed it anywhere" icon="puzzle">
    One web component, `<fluxy-gram>`, in any site, docs or app. No framework needed.
  </Card>
  <Card title="Present it live" icon="rocket">
    Full screen for the audience, your notes and a timer in a second window.
  </Card>
  <Card title="Let your agent do it" icon="star">
    A skill teaches Claude, ChatGPT, Gemini, Cursor and other agents to write great diagrams.
  </Card>
</CardGrid>
