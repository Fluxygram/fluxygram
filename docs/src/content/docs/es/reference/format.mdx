Un archivo `.flux.json` se valida con el [JSON Schema](https://fluxygram.app/schema/v1.json). Agrégalo al inicio de tu archivo para tener autocompletado y errores en tu editor de código:

```json
{ "$schema": "https://fluxygram.app/schema/v1.json", "type": "flow", "nodes": [] }
```

Las tablas de abajo se generan desde ese schema, así que siempre coinciden con lo que Fluxygram acepta. Las descripciones vienen del schema y están en inglés.

## Errores

Fluxygram valida cada archivo y explica los problemas en lenguaje simple, en español o inglés, con la ruta al campo:

```
edges[2].to: "to" apunta a "x", que no es un nodo.
steps[1].flow: "e9" no es el id de ningún nodo, conexión o grupo.
```

La misma validación está disponible en código con [`@fluxygram/core`](/es/start/install/#paquetes).
