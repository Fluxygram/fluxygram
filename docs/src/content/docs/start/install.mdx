`<fluxy-gram>` is a standard web component. It works in plain HTML and in every framework (React, Vue, Svelte, Astro, Angular…), with no wrapper.

<Tabs>
  <TabItem label="CDN">
    No install, no bundler:

    ```html
    <script type="module" src="https://cdn.jsdelivr.net/npm/fluxygram@0.1"></script>

    <fluxy-gram src="/diagrams/checkout.flux.json"></fluxy-gram>
    ```
  </TabItem>
  <TabItem label="npm">
    ```bash
    npm install @fluxygram/element
    ```

    ```js
    // Registers <fluxy-gram> once, anywhere in your app.
    import '@fluxygram/element';
    ```
  </TabItem>
</Tabs>

## Load a diagram

Point `src` at a `.flux.json` file:

```html
<fluxy-gram src="/diagrams/checkout.flux.json"></fluxy-gram>
```

Or write it inline:

```html
<fluxy-gram>
  <script type="application/json">
    { "type": "flow", "nodes": [{ "id": "a", "label": "Start" }, { "id": "b", "label": "Done" }], "edges": [{ "from": "a", "to": "b" }] }
  </script>
</fluxy-gram>
```

Or set it from JavaScript:

```js
document.querySelector('fluxy-gram').diagram = { type: 'flow', nodes: [/* … */], edges: [/* … */] };
```

## In a framework

```jsx
// React
import '@fluxygram/element';

export function Checkout() {
  return <fluxy-gram src="/diagrams/checkout.flux.json" />;
}
```

```vue
<!-- Vue: tell the compiler it's a custom element (compilerOptions.isCustomElement) -->
<template>
  <fluxy-gram src="/diagrams/checkout.flux.json" />
</template>
```

## Packages

| Package | What it is |
| --- | --- |
| [`@fluxygram/element`](https://www.npmjs.com/package/@fluxygram/element) | The `<fluxy-gram>` component. Use it with a bundler. |
| [`fluxygram`](https://www.npmjs.com/package/fluxygram) | The same component as a single file, for `<script>` tags and CDNs. |
| [`@fluxygram/core`](https://www.npmjs.com/package/@fluxygram/core) | The format without the DOM: validation, layout and motion planning. For tools, servers and Workers. |

```js
import { validate } from '@fluxygram/core';

const result = validate(json, { locale: 'en' });
if (!result.ok) console.log(result.issues); // [{ path: 'edges[0].to', message: '…' }]
```
