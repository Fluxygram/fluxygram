A `.flux.json` file is validated against the [JSON Schema](https://fluxygram.app/schema/v1.json). Add it at the top of your file to get autocomplete and inline errors in your editor:

```json
{ "$schema": "https://fluxygram.app/schema/v1.json", "type": "flow", "nodes": [] }
```

The tables below are generated from that schema, so they always match what Fluxygram accepts.

## Errors

Fluxygram validates every file and explains problems in plain language, in English or Spanish, with the path to the field:

```
edges[2].to: "to" points to "x", which is not a node.
steps[1].flow: "e9" is not the id of any node, edge or group.
```

The same validation is available in code through [`@fluxygram/core`](/start/install/#packages).
